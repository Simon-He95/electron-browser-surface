# Code of conduct

Be respectful, specific and generous with context.

We expect contributors to:

- critique ideas and code, not people;
- keep issue threads readable and on topic;
- give reproducible steps for bugs;
- respect privacy and never post credentials, private page content or user data;
- follow the project's security and responsible-disclosure guidance.

Harassment, discrimination and sustained disruptive behavior are not welcome.
Maintainers may remove comments or contributions that violate these expectations.
